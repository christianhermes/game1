# Godot-Farmingprototyp

Dieser Ordner enthält den übersichtlichen Godot-4-Prototyp für Playerbewegung,
Interaktion und Farming. Der frühere Browser-Prototyp im übergeordneten Ordner
bleibt unverändert und dient nur noch als Referenz.

## Starten

1. `project.godot` im Godot Project Manager importieren.
2. Das Projekt öffnen.
3. Mit **F6** oder **F5** starten.

## Aktuelle Steuerung

- **WASD:** Player bewegen
- **F:** Mit einem nahen Objekt interagieren

## Aktueller Szeneninhalt

- einfache 3D-Fläche mit Kollision
- Sonne und Umgebungslicht
- orthografische Kamera, die dem Player folgt
- beweglicher Player mit Interaktionsradius
- ein wiederverwendbares Weizenfeld
